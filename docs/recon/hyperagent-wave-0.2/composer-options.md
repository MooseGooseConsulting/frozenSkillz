# Composer options beneath the text box

All observations are read-only. Menus were opened and dismissed without uploading, generating output, changing a project, connecting an integration, selecting a tool, or executing a plan.

## Quick actions

- Visible actions: `Design a website`, `Source candidates`, `Research a topic`, `Generate images`, `More…`.
- `More…` opened: `Video`, `Audio`, `Slides`, `Map`, `Doc`.
- These are launch points, not passive filters; activating one would start a specialized composer/task path.

## Add files or context

Root menu branches:

- `Upload files…` — file chooser boundary; not activated.
- `Skills` — searchable skill picker; dynamic list loaded.
- `Memories` — searchable, long memory list; contents not enumerated into this report.
- `Assets` — searchable asset picker; empty-state text: “No assets yet. They’ll appear as the agent creates them.”
- `Output as…` — Image, Video, Audio, Webpage, Slides, Table, Map, Doc.
- `Integrations` — Gmail, Google Calendar, Google Drive, Slack, GitHub, Google Sheets, Google Docs, Google Tasks, Cloudflare, Firecrawl, Context7, Notion, Bright Data, Add other integrations.
- `Add to a project` — existing projects plus `Create new project…`.

## Use an agent

Picker contains a search box, six user agents (Memory Curator, Web Recon, Web Scout, Context Builder, Greenlight, Investment Analyst), one team agent (Fast Search Broker, team “Patrick’s Best Practices”), and `Create from scratch`.

## Execution mode

`Execute` opened two choices:

- `Plan first` — think through an approach and get user clarification before taking action.
- `Execute` — act immediately without a plan.

Neither mode was changed.
