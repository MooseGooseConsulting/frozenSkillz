# Cross-surface bridge

Use this reference only when the user explicitly requests a comparison between
Codex-sidebar and ChatGPT-web conversations. It never authorizes one surface's
mutation from evidence gathered only on the other.

Open both bodies and build shared conversation records before asserting that two
conversations are related or identical. Matching titles, dates, Project names,
working directories, previews, or emoji are leads, not proof. Record the
concrete shared request, artifact, decision, or explicit cross-reference that
supports every bridge.

Keep the resources separate even when a bridge is strong. Codex lifecycle
markers belong only to the Codex-sidebar title grammar. ChatGPT Project actions
are governed only by the explicit ChatGPT-web request and adapter.
