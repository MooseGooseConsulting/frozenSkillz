# obra/superpowers tooling reference

This Scout item retains a reduced reference bundle from `obra/superpowers` v6.1.1. It keeps the
plugin manifests/catalogs, OpenCode and Pi adapters, hooks, packaging/synchronization tooling,
tests, and upstream documentation useful for harness integration.

The upstream skill payload was intentionally removed. There are no `SKILL.md` files here and
nothing in this directory is an installable or active frozenSkillz skill.
