# Shared Semantic Title Rules

Use a specific title that distinguishes the conversation without reopening it:
**system or project + concrete topic/artifact + distinguishing action or outcome**.
Generic nouns, status-only labels, emoji-only titles, and decorative emoji fail.
Preserve useful exact names such as repositories, issues, pull requests, files,
or products. Prefer one to three semantic emoji; more require a distinct,
documented dimension from the taxonomy.

Measure every proposed title in UTF-16 code units and keep it at or below 60.
This is a verified Codex sidebar ceiling. It is a conservative ChatGPT target,
not a claimed ChatGPT platform limit. Trim words before deleting the concrete
artifact or semantic meaning.

Semantic category emoji describe content or work type. They are not lifecycle
status markers except in the Codex adapter, which has its own status grammar.
Use the taxonomy's ambiguity warnings and renderer notes. Do not use a Unicode
Emoji v18.0 beta entry until Chrome rendering is confirmed in the actual client.
